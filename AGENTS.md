## Agent skills

Issues 与 specs 存放在 GitHub Issues，统一用 `gh` CLI 读写。See `docs/agents/issue-tracker.md`.

五个 canonical triage roles：`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

single-context：根目录 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
